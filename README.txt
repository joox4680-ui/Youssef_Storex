Youssef_Storex - prototype

Run locally: open index.html in a modern browser.
Admin page: admin.html
Demo admin password: YS2026

IMPORTANT LIMITATIONS:
- This is a front-end prototype. Settings and orders are stored in the current browser's localStorage only.
- The admin password is client-side demo protection, NOT secure authentication.
- For a public launch with real customers, connect a backend/database, secure server-side admin authentication, and server-side order storage.
- WhatsApp order destination is preconfigured to 201227540023 (Egypt international format without +). You can change it from admin settings.
- Bundle prices and stock start at zero and can be set in the admin page.
